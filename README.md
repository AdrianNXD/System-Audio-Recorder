You need an easy application to record your system sound? This is it.

## Usage
Click "Record" to record. Click "Stop" to stop. That's it. The workflow is easy. If you click "Record" again or click "Cancel" in the file dialogue the recording will be discarded. 

Files will be saved as high quality 320 kbps MP3 files. 

## Requirements

This app needs some Python packages. Just install them when missing them. Should work across different versions. 

App also needs FFMPEG installed on your machine with PATH environmental variables set. This means that when typing "ffmpeg" in the terminal you should not get an error that it is a unknown command..

## Future Work

Future changes could include different bit rates or .WAV option. But the app was intended to be super simple.
